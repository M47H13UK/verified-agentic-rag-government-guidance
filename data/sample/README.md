# Sample data

Real GOV.UK responses, fetched on 5 October 2026. Tests use them, so the test suite needs no network.

| File | What it is |
| --- | --- |
| `search-facets.json` | Search API count of UK Visas and Immigration documents by format |
| `search-guides.json` | Search API listing of the 101 guides |
| `content-graduate-visa.json` | Content API response for a guide with 6 parts |
| `content-skilled-worker-visa.json` | Content API response for a guide with 14 parts |
| `content-employee-lose-sponsor-licence.json` | Content API response for an answer page, which has a body and no parts |
| `passages.json` | The 13 passages built from the Graduate visa guide |
| `quotes.json` | 5 quotes that appear word for word in those passages |
